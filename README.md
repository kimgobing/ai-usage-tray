# AI 사용량 트레이

작업 표시줄 트레이에서 **Claude**와 **ChatGPT(Codex)**의 5시간 세션·주간 한도 사용량을 보여 주는 Windows 프로그램입니다.
사용률, 리셋까지 남은 시간(또는 복구 시각), 지금 속도로 리셋 전에 다 쓰게 되는지를 알려 줍니다.

## 설치

1. [최신 설치 파일 받는 곳](https://github.com/kimgobing/ai-usage-tray/releases/latest)에서 `ai-usage-tray-setup-*.exe`를 받습니다.
2. 실행합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (공식 인증서로 서명하지 않은 개인 프로그램이라 나오는 경고입니다.)
3. 한 번 설치하면 새 버전은 자동으로 업데이트됩니다.

## 필요한 것

- Windows 10/11 (64비트)
- Claude 사용량: Claude Code 설치 + 로그인
- ChatGPT 사용량: Codex CLI 설치 + 로그인

## 개인정보

- Claude Code / Codex 로그인 정보는 읽기만 하고 저장하거나 기록하지 않습니다.
- 접속하는 곳은 Claude 서비스(api.anthropic.com)와 업데이트 확인용 GitHub뿐입니다.
